A digital wedding invitation website for **Aravindh & Karthiga**.

- **Bride & Groom**: Aravindh (S/o Manikandan & Selvamary) & Karthiga (D/o Balamurugan & Chitra)
- **Engagement Ceremony**: Saturday, 14th November 2026, 7:00 PM onwards
- **Wedding Ceremony**: Sunday, 15th November 2026, 8:00 AM – 9:15 AM
- **Venue**: Aaryan Thirumana Mahal, 1/237, Alagar Kovil Main Road, Janki Nagar, Kathakinaru, Madurai, Tamil Nadu 625104
- **BGM**: YouTube Short (`OiADjLFGiF4`)

## Tech Stack
- Next.js (App Router, Static Export `output: 'export'`)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lenis Smooth Scroll
- Lucide Icons

## Getting Started
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
Static files are exported directly into the `out/` directory.
